Download the APK

The file is named chapter-and-verse.apk and is downloaded from GitHub. All releases and SHA-256 checksums.

How to install Moonleaf

  1. Download the APK. On your phone, tap Download the APK above.
  2. Open the file. When the download finishes, open chapter-and-verse.apk from the notification or your Downloads folder.
  3. Allow the install. If Android says your browser isn’t allowed to install unknown apps, tap Settings, turn on Allow from this source, then go back.
  4. Install and open. Tap Install, then Open. Tap + in the Library tab and paste a story or chapter link, or open an EPUB file you already have.

Why does Android warn me? Apps installed outside Google Play always show this prompt, and Play Protect may ask you to scan the app. Moonleaf asks for no special permissions beyond internet access for fetching chapters.

Updating to a new version

Download the latest APK from this page and install it over the old one. See what’s new in the latest version. If Android says the app conflicts with an existing package, the new build was signed by a different build machine. Uninstall Moonleaf first, then install the new APK. Uninstalling removes your library, so save any EPUBs you want to keep before you do.

Verify the download (optional)

Each release on GitHub includes a chapter-and-verse.apk.sha256 file. Compare it with the checksum of your download, for example with sha256sum chapter-and-verse.apk on a computer.

Other platforms

Moonleaf is built with Flutter and runs on iOS, macOS, Windows and Linux when built from the source code. Only the Android APK is published as a download.

Troubleshooting

  • “App not installed”: make sure you have enough free space (about 600 MB) and that an older build signed differently isn’t still installed.
  • A novel won’t download: check that the link is a story or chapter on a supported site (Royal Road, Scribble Hub, FanFiction.net, AO3, Standard Ebooks, RoliaScan or Indra Translations), that it’s text, not image-only manga, and complete the site’s human check if Moonleaf shows one.
  • Found a bug? Report it on GitHub.
